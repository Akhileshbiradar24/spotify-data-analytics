# Spotify Data Analytics

## Project Overview
This project analyzes Spotify's Top 10,000 tracks from 1960 to the present using Python. It covers data preprocessing, exploratory data analysis (EDA), and confirmatory data analysis (CDA).

## Files
- `spotify_analysis.py` — Python script for cleaning, analysis, statistical tests, and visualizations.
- `top_10000_1960-now.csv` — Original dataset.
- `spotify_cleaned.csv` — Cleaned dataset generated during preprocessing.

## Technologies Used
- Python
- Pandas
- NumPy
- SciPy
- Statsmodels
- Matplotlib

## Analysis Performed
- Data cleaning and duplicate removal
- Descriptive statistics
- Correlation analysis
- Chi-square tests
- Simple linear regression
- Multiple linear regression
- Data visualization

## How to Run
1. Install Python.
2. Install the required libraries:

   `pip install pandas numpy scipy statsmodels matplotlib`

3. Place all three project files in the same folder.
4. Run:

   `python spotify_analysis.py`

## Notes
The script uses the original dataset to generate the cleaned dataset when the original CSV is available. Otherwise, it can load the cleaned dataset directly.
